# 山十 行先予定表 Ver.3.3

Ver.3.2 のSupabase認証・社員管理・部署/職種マスタ管理を維持し、CSV社員一括登録を追加した版です。

## 追加機能
- 管理設定 > 社員管理に「CSV一括登録」ボタン追加
- ExcelテンプレートをCSV UTF-8で保存して一括登録
- ログインID、初期パスワード、氏名、部署、職種、権限を一括読込
- 部署/職種マスタ照合
- 既存ログインID/CSV内重複チェック
- 登録前プレビューと入力エラー表示
- 登録進捗表示
- 成功/失敗件数の結果表示
- エラー行CSVの再出力
- CSVひな形を画面からダウンロード

## CSV列
日本語ヘッダーまたは英語ヘッダーを利用できます。

- ログインID / login_id
- 初期パスワード / password
- 氏名 / name
- 部署 / department
- 職種 / job_type（空欄可）
- 権限 / role（一般/user、管理者/admin）

## 注意
- Excelからは「CSV UTF-8（コンマ区切り）」で保存してください。
- 初期パスワードは8文字以上です。
- 部署/職種は使用中のマスタ名と完全一致させてください。
- `supabase-config.js` は現在正常に動作している値をそのまま利用してください。
- Secret keyはGitHubに置かないでください。
