# 山十 行先予定表 - GitHub Pages版

追加契約なしで、まず行先板の操作感を確認するための静的Webアプリ版です。

## 現在できること
- PC / iPad / iPhone / Android対応
- 社員一覧、部署・状態絞り込み、検索
- 在席 / 外出 / 現場 / 会議 / 出張 / 休み
- 行先、用件、戻り予定、電話対応可否、直行・直帰、メモ
- 予定登録
- 時刻到達時の自動切換え（画面を開いている間）
- 変更履歴
- 社員追加
- 大型モニター表示

## 重要な制限
この版は localStorage を使うため、データは「そのブラウザ」に保存されます。
複数PC・スマホ間では共有されません。ブラウザデータ削除で消えます。

## GitHub Pagesで無料公開する場合
GitHub FreeではGitHub PagesはPublicリポジトリで利用できます。PrivateリポジトリでのPages公開はPro/Team等が必要です。
この版には実在社員データやAPIキーを直接入れず、公開しても問題ないコードだけ置く前提です。
