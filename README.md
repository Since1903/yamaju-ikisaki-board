# 山十 行先予定表 - GitHub Pages版 Ver.2.2.1

追加契約なしで試せる静的Webアプリ版です。

## Ver.2.2.1 追加点

- 「管理設定」を追加
- 状態マスタを画面上から追加・編集・停止・再開・削除
- 状態名、カード色、並び順を管理
- 状態ごとに「戻り予定を使う／使わない」「行先を使う／使わない」「初期の行先」を設定
- 状態の並び順を ↑ ↓ で変更
- 使用中の状態は誤削除を防止
- 停止した状態は新規の状態選択から除外し、既存データ・履歴は保持
- 状態マスタの操作履歴も履歴画面に保存
- 表示設定ダイアログの横スクロール問題を修正
- 状態色は「管理設定」に集約

## 既存機能

- PC / iPad / iPhone / Android対応
- 部署・職種・状態で絞り込み
- 自分を左上に固定
- 表示する社員を端末ごとに設定
- 状態ごとにカード全体を色分け
- 予定登録（開始・終了時刻）
- 自動切換え
- 手動変更・予定登録・自動切換え・状態マスタの履歴表示
- 大型表示

## 注意

この版は GitHub Pages 上で動くため、データは各ブラウザの localStorage に保存されます。別端末とのデータ共有・本物のログイン認証は未実装です。
