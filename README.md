# 山十 行先予定表 Ver.4.4

## Ver.4.4 追加機能：休み掲示板

予定登録で状態を **「休み」** にした予定を、自動で「休み掲示板」に表示します。

### 表示仕様

- 下部メニューに **「休み掲示板」** を追加
- 表示項目は **日付 / 氏名** のみ
- 日付が近い順に自動整列
- 同じ社員・同じ日付に複数の「休み」予定がある場合は1件にまとめて表示
- 当日の休みはその日いっぱい表示
- 日付を過ぎた予定は掲示板には表示しない
- 予定を削除した場合は掲示板からも自動で消える
- `schedules` のRealtime更新・定期再取得に連動するため、PC・スマホ・タブレット・大型表示で共通表示

## 既存機能

Ver.4.1までの以下の仕様を維持します。

- 複数予定が重なった場合は、現在有効な予定のうち開始時刻が最も新しい予定を優先
- 同じ開始時刻なら後から登録された予定を優先
- 優先予定終了後は、まだ有効な次順位の予定へ自動復帰
- Supabase Cron + クライアント補助処理による開始・終了処理
- Realtime + 定期再取得による全端末同期

## Ver.4.2 / Ver.4.3 のSupabase設定について

このフロントエンド更新は、すでに設定済みの以下のSupabase側変更をそのまま利用できます。

- 部署ごとの `default_location`（予定終了時の在席初期拠点）
- 毎日0:10（日本時間）の終了済み過去予定自動削除

**Ver.4.4では追加SQLは不要です。**
