# 山十 行先予定表 Ver.4.7

## Ver.4.7 追加機能：全休の期間指定

「全休」だけ、1日ではなく複数日の休暇を1件の予定として登録できるようにしました。

### 予定登録

- 状態が **全休** の場合
  - 開始日と終了日を指定できます
  - 開始・終了時刻の入力は不要です
  - 内部では開始日の 0:00 から終了日の 23:59 までの予定として扱います
- **午前休 / 午後休 / 時間休** は従来どおり1日単位です
- 通常の「外出・会議・現場・出張」等も従来どおり同日内の開始・終了時刻で登録します

### 休み掲示板

表示項目は **日付 / 休みの種類 / 時間 / 氏名** です。

例：

- `9/1（月）～9/3（水） | 全休 | 3日間 | 山田 太郎`
- `9/2（火） | 全休 | 1日 | 田中 一郎`
- `9/4（木） | 午前休 | 午前 | 佐藤 次郎`
- `9/5（金） | 時間休 | 13:00～15:00 | 鈴木 花子`

期間途中の全休予定も、終了日を過ぎるまでは掲示板に表示されます。

## 既存機能

- 複数予定が重なった場合は、現在有効な予定のうち開始時刻が最も新しい予定を優先
- 同じ開始時刻なら後から登録された予定を優先
- 優先予定終了後は、まだ有効な次順位の予定へ自動復帰
- 部署ごとの `default_location` を使った在席復帰
- Supabase Cron + クライアント補助処理による開始・終了処理
- Realtime + 定期再取得による全端末同期
- 毎日0:10（日本時間）の終了済み過去予定自動削除

## Supabase設定

Ver.4.7では新しいテーブル列やSQL関数は追加しません。
既存の `schedules.start_at` / `end_at` を複数日にまたがる日時として利用します。

**追加SQLは不要です。**

## Ver.4.7 追加機能：消しゴム（在席に戻す）
- 行先板の「自分」のカードにだけ「⌫ 在席に戻す」ボタンを表示します。
- 押すと、状態を「在席」、行先を部署マスタの `default_location` に戻します。
- 用件・戻り時間・直行・直帰・メモをクリアし、電話状態を `ok` に戻します。
- 押した時点で実行中の自分の予定がある場合、その予定は `end_done = true` として終了扱いにします。未来の予定は削除・終了しません。
- 大型モニターモードでは誤操作防止のためボタンを非表示にします。
