# 山十 行先予定表 - GitHub Pages版 Ver.2

追加契約なしで試せる静的Webアプリ版です。

## Ver.2 追加点
- 状態ごとにカード全体の色を変更（色は「表示設定」から変更可能）
- 「休み」は初期値で水色
- 部署・状態に加えて職種でも絞り込み
- 「自分」を常に左上へ固定
- 表示したい社員を端末ごとに選択
- 予定に開始・終了時刻を設定
- 予定終了時に在席へ自動復帰、または予定前の状態へ復帰
- 連続予定では次の予定を優先
- 予定一覧に開始・終了時間を表示
- 履歴に予定登録時刻・開始時刻・終了時刻・自動開始/終了を記録
- 在席/休み/直帰に応じた入力制御

## 重要な制約
GitHub Pagesだけでは、安全なID・パスワード認証、複数端末間の共有データベース、バックグラウンド常時実行はできません。
Ver.2の「表示設定」はこのブラウザ（localStorage）単位です。

本物のアカウント管理を行う場合は、後段で認証・データ保存用のバックエンドを追加してください。
