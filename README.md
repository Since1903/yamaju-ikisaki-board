# 山十 行先予定表 Ver.3.2

Ver.3.1 のSupabase認証・社員管理・リアルタイム共有を維持し、部署・職種マスタ管理を追加した版です。

## 追加機能
- 社員追加・修正時の部署を部署マスタから選択
- 社員追加・修正時の職種を職種マスタから選択（未設定可）
- 管理設定から部署の追加・編集・停止・再開・削除・並び替え
- 管理設定から職種の追加・編集・停止・再開・削除・並び替え
- 部署・職種名を変更した場合、該当社員の設定も自動更新
- 使用中マスタは削除不可

## 重要
Ver.3.2を使う前に `MASTER_POLICIES.sql` をSupabase SQL Editorで1回実行してください。
これは管理者だけが departments / job_types を変更できるRLSポリシーを追加します。

`supabase-config.js` は現在正常に動作しているものをそのまま使ってください。Secret keyはGitHubに置かないでください。
