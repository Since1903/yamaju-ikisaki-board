# 山十 行先予定表 - GitHub Pages版 Ver.2.1

Ver.1の見た目をベースに、Ver.2の機能を維持した表示崩れ修正版です。

## Ver.2.1 修正点
- ヘッダー・検索・フィルター・ボタンをVer.1のデザインへ戻して安定化
- 状態色を社員カード全体へ確実に反映
- 「休み」は水色を初期値に設定
- CSS/JSにバージョン番号を付け、GitHub Pagesの古いキャッシュを回避
- 在席・休み・直帰時の「戻り 00:00」を表示しない

## Ver.2から維持している機能
- 部署・職種・状態で絞り込み
- 自分を左上に固定
- 端末ごとの表示社員設定
- 状態ごとの色変更
- 予定の開始/終了時刻
- 自動切換え
- 予定時間を含む履歴表示
